# YOLO Real-Time Person Tracking & IN/OUT Counter

A computer vision project built with Python, YOLO, OpenCV, and Streamlit to detect and track people through a live webcam feed. The system counts people entering and leaving an area and displays total IN and OUT statistics through an interactive dashboard.

## Features
- Real-time person detection using YOLO
- Live webcam tracking
- IN/OUT counting based on movement across a counting line
- Live counting statistics
- Total IN and OUT counts retained after the camera stops
- Streamlit-based user interface
- CPU-compatible inference

## Technologies
- Python
- YOLO (Ultralytics)
- OpenCV
- Streamlit
- NumPy

## Run the Project

Install dependencies:

```bash
pip install streamlit opencv-python ultralytics numpy
```

Start the application:

```bash
streamlit run main.py
```

Allow webcam access if prompted.

## Applications
- Shops and restaurants
- Office entrances
- Classroom occupancy
- Visitor counting
